# GoGreen Recycling System 🌱

A web-based recycling system using:
- Apache
- PHP
- MySQL
- JavaScript

Features:
- Recycling point system
- Quiz rewards
- Smart map
- Redeem system
- Admin dashboard
- Export to Excel

How to run:
1. Install XAMPP
2. Put project in htdocs
3. Import database
4. Run localhost/gogreen

🔄 Update Project
git add .
git commit -m "update"
git push

▶️ Setup Project
🔧 Option 1: Clone terus (recommended)
cd /c/xampp/htdocs
git clone https://github.com/Azwan06/GoGreen-Workshop.git GoGreen

🔧 Option 2: Folder dah ada (manual connect)
cd /c/xampp/htdocs/GoGreen
git init
git remote add origin https://github.com/Azwan06/GoGreen-Workshop.git
git pull origin main --allow-unrelated-histories
